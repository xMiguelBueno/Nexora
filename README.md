# Nexora

Sistema pessoal de organização e evolução.

## Versão local
O Nexora possui um Organizador baseado em regras locais. Ele não depende de Anthropic, OpenAI, API key ou créditos para funcionar.

Principais comandos: criar tarefas, criar hábitos, criar metas, registrar água e refeições, concluir/reagendar tarefas, consultar progresso e organizar o dia.

## Rodar
```bash
npm install
npm run dev
```

## Deploy
Pode ser publicado diretamente na Vercel como um projeto Vite estático. Não há variável `ANTHROPIC_API_KEY` necessária.
